# 你回覆給使用者的格式（建議）

當你要新增/修改 UI 時，回覆請包含以下三段（簡短即可）：

1. `修改重點`：你判斷需求屬於哪一類檔案層級（頁面/組件/dialog/map/styles）
2. `將改哪些檔案`：列出 3-6 個最核心檔案路徑
3. `如何驗證`：給出 1-3 個可操作的驗證步驟
